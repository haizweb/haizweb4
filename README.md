# FS 50 — скролл-сайт с 3D-часами (Three.js)

Сайт повторяет по видео `IMG_8132.MP4` одностраничный скролл-проект с часами: светлый hero «ELEGANT CONTOURS», тёмная секция с вихрем частиц, «механическое сердце» с волокнами-канатами, разлёт и сборка деталей часов, светлая секция «TIMELESS AUTOMATIC» и финал «FS 50» со стеклянным сектором и перетаскиванием (DRAG).

Все 3D-объекты построены кодом (исходных моделей у видео нет): часы, механизм, ротор, цифры, стрелки, браслет, частицы и канаты — настоящая геометрия Three.js, никаких картинок-заглушек. Текстуры (сатин, перлаж, циферблат с «солнечным» лучом, гравировка на ободе) генерируются на canvas при загрузке, окружение для отражений — процедурная «фотостудия» (PMREM).

## Запуск

Нужен только Node.js 18+ (или любой статический сервер). Ничего устанавливать не надо — Three.js лежит в `vendor/`.

```bash
cd watch-site
node server.mjs          # http://localhost:5173
# или: npm start
# или: python3 -m http.server 5173
```

Открывать нужно по `http://`, а не двойным кликом по `index.html` (ES-модули не работают с `file://`).
Нужен браузер с WebGL 2 (Chrome, Edge, Firefox, Safari 16.4+).

## Управление

| Действие | Что происходит |
| --- | --- |
| колесо мыши / тач / полоса прокрутки | прокрутка истории (≈ 9 экранов) с инерцией |
| `↓` `PageDown` `Space` / `↑` `PageUp` `Shift+Space` | переход к следующей / предыдущей сцене |
| движение мыши | параллакс: камера, часы и текст чуть смещаются по глубине |
| финал: зажать и тянуть | часы вращаются с инерцией, через пару секунд возвращаются на место; сектор следует за вращением |

Отладка: `?p=0.42` фиксирует прогресс прокрутки, `?still=1` — один кадр с фиксированным временем (для скриншотов), `?intro=0.4` — кадр вступительной анимации.

## Сцены (прогресс прокрутки)

| p | Сцена |
| --- | --- |
| 0 – 0.06 | hero: заголовок выезжает из масок, часы поднимаются и разворачиваются |
| 0.06 – 0.26 | часы совершают полный оборот, по диагонали «вытекает» тёмный стальной фон |
| 0.20 – 0.40 | тёмная секция «FS—50R / THE PRECISELY AUTOMATIC MOVEMENT», часы растворяются в вихре частиц |
| 0.33 – 0.58 | «MECHANICAL HEART»: канаты из сотен волокон, диск механизма с шестернями и ротор |
| 0.56 – 0.78 | светлый фон возвращается, детали влетают (циферблат, увеличенные цифры, корпус, кольцо браслета) и собираются |
| 0.77 – 0.90 | «THE TIMELESS AUTOMATIC», часы уезжают вправо |
| 0.87 – 1.00 | финал «FS 50», стеклянный сектор, «MODEL 146GR», перетаскивание |

## Структура

```
index.html            разметка: фон, слои текста (за canvas и над ним), canvas, курсор DRAG
server.mjs            статический сервер без зависимостей
src/main.js           рендерер, сцена, скролл, ввод (параллакс, drag), цикл кадров
src/timeline.js       вся хореография как функция прогресса p (позы, слои текста, частицы)
src/styles.css        типографика, слои, адаптив (в т.ч. портретный режим)
src/core/             math (easing, Track), scroll (инерция), stage (экран → мировые координаты)
src/gl/watch.js       модель часов: корпус, циферблат, цифры, стрелки, браслет из 22 звеньев
src/gl/movement.js    диск механизма и ротор
src/gl/particles.js   вихрь частиц и канаты-волокна (шейдеры)
src/gl/textures.js    процедурные текстуры, env.js — студийное окружение
src/gl/glyphs*.js     контуры цифр Montserrat → выдавленная 3D-геометрия
vendor/three/         Three.js r186 (MIT), только нужные файлы
assets/fonts/         Montserrat (OFL)
tools/                скриншоты и сквозной тест (Playwright, только для разработки)
```

## Производительность

- один `WebGLRenderer`, прозрачный canvas поверх DOM-типографики;
- частицы и канаты считаются в вершинных шейдерах (на CPU ничего не анимируется);
- адаптивное разрешение: при просадке кадров `devicePixelRatio` автоматически снижается до 1;
- модели не загружаются файлами — нет сетевых запросов, кроме одного шрифта и Three.js;
- на телефонах (`hover: none`) кастомный курсор отключён, на портретных экранах используется отдельная раскладка.

## Что восстановлено «по смыслу»

Видео снято на телефон с монитора, поэтому часть мелких текстов читалась плохо: абзац под заголовком hero и подписи «Calibre 146» / «Automatic Movement» написаны заново по смыслу, а их положение, размер и цвет взяты из кадров. Точные размеры шрифтов, межстрочные интервалы и позиции часов выверены по кадрам видео (hero, статементы, финал), траектории деталей в сцене разлёта и форма канатов воссозданы приближённо.
